
# Task 04 - Traffic Accident Analysis

## Project Overview
This project focuses on analyzing traffic accident data to identify patterns related to road conditions, weather conditions, and time of day.

The main objective is to understand accident trends, identify contributing factors, and visualize accident hotspots using Python.

## Dataset Information
- Dataset: UK Road Safety - Traffic Accidents
- Total Records: 101,525
- Total Columns: 44
- Year: 2025
- Data Format: CSV

## Tools & Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Folium

## Data Cleaning
The following data preparation steps were performed:
- Loaded the CSV dataset using Pandas.
- Checked dataset shape and column information.
- Identified missing values.
- Checked duplicate records.
- Analyzed data types.
- Processed date and time information.

## Analysis & Key Findings
The analysis focused on:
- Accidents by time of day.
- Accidents by day of the week.
- Weather conditions.
- Road surface conditions.
- Accident severity.
- Speed limits.
- Urban and rural accident distribution.

### Key Findings
- Total accident records: 101,525
- Total casualties: 127,883
- Duplicate records: 0
- Missing values: 8
- Most accidents occurred at 5 PM.
- Friday recorded the highest number of accidents.
- Urban areas recorded more accidents than rural areas.
- Dry road conditions had the highest accident count.
- 30 mph roads recorded the highest number of accidents.

## Graphs and Accident Hotspot Map
Visualizations were created to understand:
- Time-wise accident patterns.
- Day-wise accident distribution.
- Weather and road surface conditions.
- Accident severity.
- Geographical accident hotspots.

The hotspot map uses a sample of 20,000 valid accident locations.

## Conclusion
This analysis provides useful insights into traffic accident patterns in the UK during 2025.

It highlights the relationship between accident records, weather, road conditions, time, and geographical locations.

These findings can help understand road safety trends and support further traffic safety analysis.
